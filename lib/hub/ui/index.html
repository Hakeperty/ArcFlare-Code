              Turn on YOLO mode?

              This agent will run commands and change files on your computer without asking you first.

              • A wrong or misunderstood instruction can delete or overwrite your work.
              • Anything the agent reads can steer it: a web page, a file or a tool result can contain instructions.
              • You will see what it did in the conversation, but only after it has run.

              Use it in a project you can afford to lose or have backed up, like . It stays on for this agent until you turn it off.

              Turn on Team mode?

              This agent gets a team, all on your computer: small helper models that search and read the project in parallel, and an advisor, a stronger model that checks the work but never writes code.

              Answers will be slower, often by a minute or more:

              • Before it starts, the advisor reads the task and makes a plan: usually 10 to 30 seconds. Small talk like "thanks" skips it.
              • Before it says it is done, the advisor reviews the work, including the actual changes on disk, and it may send the agent back to fix things. Answers that changed nothing are not reviewed.
              • Helpers and advisor take turns in a second model server. Loading one takes 5 to 15 seconds each time they swap.
              • It needs GPU memory for the helpers, so the main model gets a shorter memory of the conversation (context), and helper models that do not fit are skipped.

              In return it should catch more mistakes, like an edit that failed but was reported as done. The agent restarts with its conversation kept.

              Sign out other devices?

              Every other browser and phone will need to sign in again. This device stays signed in.
