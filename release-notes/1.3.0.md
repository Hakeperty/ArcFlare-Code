ArcFlare 1.3.0: agents can call your phone, and a small AI runs on the phone itself.

## The phone app and hub

- A second Android app, ArcFlare Agent, is built with a files plugin and its own updates.
- The phone app can update itself from arcflare.net, with no computer and no sign-in.
- The phone's Tools screen shows the builder panda when there are no MCP servers yet.
- The phone's call list shows the panda when there are no calls yet.
- Phone: choose an Arc and switch on the web and desktop servers, remembered on the computer.
- Phone: MCP tools for agents, chat instructions, regenerate, copy, search, richer markdown.
- Phone chat list: rename in place, and delete asks for a second tap.
- Phone: Queue button lines messages up while an agent works.
- Phone: delete agents for real, and one-time agents and chats that delete themselves.
- ArcFlare Connect keeps its address across hub restarts.
- The app's licence list is shown on the pairing screen, before sign-in.

## Calls from agents

- Agents can call your phone: call_phone rings it, speaks, listens and records the call.
- Calls say they are recorded, and the agent treats heard speech as data, not orders.
- Mute agent calls and sounds from the phone, with sounds per notice kind, only 07:00-23:00.
- Agents can schedule a call: the phone rings at a set time and says the agent's line.
- Answer or decline a call from an agent with a message instead of talking.
- Answer a call from an agent with one tap: Yes, No, Later or Stop. A double tap on Answer no longer ends the call.
- A call you miss leaves the agent's message on the phone, and the agent is told so.
- See past calls from agents on the phone: what was said, how each ended, and play them back.
- call_phone no longer guesses why a call came with no recording.
- call_phone no longer says a call was answered by message when nobody answered at all.
- call_phone refuses a set time for a call that is already under way.
- The call list keeps a decline message as you wrote it.

## AI on the phone

- Chat with Arc Pocket on the phone itself, with no computer and no internet.
- Arc Pocket: a small Arc for phones and computers with little memory.
- Arc Pocket Agent: a new Arc with instructions and file tools for the agent app on a phone.
- ArcFlare Agent: Arc Pocket reads and writes files in a folder you share, asking each time.
- Local AI gives your message back when an answer fails, and says when it forgets old ones.
- Local AI: half-finished downloads are deleted, and a cut-off answer says so.

## Agents and Team mode

- Team mode: a local lead, helper swarm and advisor for one agent.
- Team mode: faster advisor, diff-based review, and checked helper answers.
- YOLO mode for one agent, from the phone, behind a warning.
- YOLO keeps working: no stopping to ask, and one "done" notification at the end.
- A default workspace: agents always have a folder, with no path to remember.
- A headless browser for the agent: open, read, click, type.
- Agents can search the web and read a page as text, with its links numbered. Only public addresses are reached.
- Skills can be switched off without removing them.
- arcflare skills lists agent skills and switches one on or off from the command line.
- Codex config: only top-level keys are replaced, so model settings in your own tables are kept.

## Models, Arcs and the Store

- The ArcFlare Store: skills, MCP servers and models in one place.
- The store names the host the catalogue actually came from.
- Five ArcSkills in the store: short, step-by-step skills for the Arc models.
- The offline catalogue has 173 models instead of 56.
- Arcs are Modelfiles, and arcflare create makes your own.
- Arcs: ArcFlare's own models, and an agent that knows which tools are on.
- Hub entries for Arcs install with arcflare arcs pull.
- arcflare pull takes the full-resolution vision projector and the root copy of a model.
- arcflare pull shows what an abliterated or uncensored build is, and asks for yes.
- Models with a built-in draft head run about twice as fast.
- Faster generation: n-gram speculative decoding is on by default (arcflare spec on|off).
- Arc chat samples the way the base model's authors tuned it.
- Arc Red downloads its model from DuoNeural's own repository.

## Speech

- Speech is easier: arcflare say, install on first use, voice design, saved voices, OmniVoice, Kitten TTS 2.
- One-command speech installs, tested from an empty home and on a fresh GPU environment.
- Calls can speak with a speech model on your computer instead of the phone's own voice.
- A speech model that hangs no longer leaves a call silent: the phone's voice takes over.
- A slow first line no longer kills the computer's voice for the call: the phone waits 10 seconds.

## Linux and macOS

- Linux: desktop control on Wayland (sway, Hyprland and other wlroots compositors), and the Wayland clipboard no longer hangs.
- Linux: desktop control on X11, and macOS desktop control through screencapture and osascript. The macOS path has not been run on a Mac yet.
- Linux: start installed apps, read AMD and Intel GPU memory, see firewalls and port owners.
- ArcFlare Connect on Linux waits for a real connection, falls back to HTTP/2, and pairs without a home network.

## Security

- File tools refuse network and device paths before touching the disk, so a prompt-injected read cannot leak a hash.
- write_file and edit_file check the path again after the approval wait, so a swapped link is not followed out of the roots.
- Only owners can allow an approval or answer a local agent's question. Any account may still deny.
- Team mode runs git without asking, and a repository's own config can no longer make it run programs.
- YOLO agents take work from owners only: a non-owner account cannot start, wake or queue work for them.
- arcflare report says reports are private, as the site now does.

## Fixes

- The phone app no longer closes when you tap Use AI on this phone, and Local AI shows an error instead of closing
  the app if a download, Stop or unload fails.
- Deleting a model while it downloads stops the download, and the model no longer comes back when it ends. Only one
  model downloads at a time.
- Ending a call while the phone is still listening no longer risks a crash in the app.
- The One-time chat button no longer spills past the screen edge, and the agent bar no longer cuts off Start on narrow screens.
- Phone app builds from CI can install as an update over the app instead of being refused.
- The cloudflared download gives up after 30 seconds for the release lookup and 10 minutes for the download, and says which one timed out.
- The Cloudflare mailbox listener catches any error from a request, so one bad request cannot stop the hub.
- Skill descriptions written over several lines are read whole, so the model no longer skips those skills.

Update with `arcflare update`. The Android app updates itself from arcflare.net: tap Update the app on its pairing screen.
