ArcFlare 1.3.1: pinning an installed model with a slash in its name no longer fails.

## Fixes

- Pinning an installed model to a phone agent no longer fails with "That model is not on this computer" when the model's name has a slash in it, such as hf.co/unsloth/qwen3-gguf:q4_k_m.

Not changed: arcflare run and the other command-line commands were not affected by this, and no cause has been found yet for the command-line errors that were also reported. If you still see a model reported as missing, send the exact message and the output of arcflare ls and arcflare ps.

Update with `arcflare update`. The Android app does not need an update for this fix.
