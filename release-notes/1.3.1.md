ArcFlare 1.3.1: pinning an installed model with a slash in its name no longer fails, and ArcFlare Agent can be set as the phone's assistant.

## The phone app

- ArcFlare Agent can be set as the phone's digital assistant, and the assist gesture then opens Arc Pocket on the phone. It has not been tried on a phone yet.
- While ArcFlare Agent is the assistant, apps that ask for the phone's default speech recognizer may be sent through it. It passes each request on to another installed recognizer (Google's first, else any other) and records nothing itself. Which apps this affects has not been confirmed.

## Fixes

- Pinning an installed model to a phone agent no longer fails with "That model is not on this computer" when the model's name has a slash in it, such as hf.co/unsloth/qwen3-gguf:q4_k_m.

Not changed: arcflare run and the other command-line commands were not affected by this, and no cause has been found yet for the command-line errors that were also reported. If you still see a model reported as missing, send the exact message and the output of arcflare ls and arcflare ps.

Update with `arcflare update`. The model fix needs no phone update. ArcFlare Agent updates itself from arcflare.net: tap Update the app on its pairing screen.
