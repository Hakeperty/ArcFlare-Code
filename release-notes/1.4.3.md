ArcFlare 1.4.3: add MCP tool servers from the phone, and the phone AI reads long files to the end.

## Changes you may notice

- **An owner can add MCP tool servers from the phone.** On Tools, tap Add a tool server, pick one from the ArcFlare Store and tap Add. Servers that need a folder ask for one. The phone shows the exact command; your computer builds it from its own copy of the store, so the phone can only pick from the list.
- **A new server is added switched off.** Switching it on runs its command on your computer, as you, and may download the program first. Every tool call still asks you first.
- **Servers added from the store have a Remove button** (tap twice), unless you added extra options to them on the computer. ArcFlare's own servers and servers you wrote in `~/.arcflare/mcp.json` yourself cannot be removed from the phone. Other accounts cannot add or remove servers.
- **Arc Pocket Agent reads a long file to the end and writes lists it used to refuse.** Its instructions are rewritten (Modelfile and phone page).

## Fixes

- Adding or removing a store MCP server keeps `mcp.json` private if you made it so
- A stale temp file no longer gives `mcp.json` the wrong permissions for a moment
- Adding a server from the phone refuses if the store entry changed after you saw it
- Removing a server from the phone keeps it if it was edited on the computer meanwhile
- Errors shown on the phone no longer reveal where `mcp.json` is, even when the path has spaces or an apostrophe
- Adding a store server refuses an argument that starts with a dash, in the CLI and on the phone
- Long error text from a tool server no longer slows the phone hub

## Not done, and not checked

- Nothing ran on a phone. The new screens were checked in Chromium at phone width (13 of 13 phone flows in `scripts/e2e-phone.js`, run on this release's code) and by tests.
- The phone AI figures come from our own test runs (75 per setting, 15 tasks times 5, not published; the harness is local only) with Qwen3-1.7B Q8_0 on a 4-core Linux computer, not a phone: 64 of 75 runs completed correctly, against 35 of 75 before. "Count from 1 to 50 in words" and a 600-word essay still fail every time. Answers take about twice as long on average (18.9 s against 9.9 s a run there).
- The Arc Pocket Agent cannot use MCP servers itself yet. Agents started from the phone can use a server once you switch it on.
- The phone page is a copy bundled inside the Android app: these phone changes reach a phone with a new app build.
- On Windows, a folder given to a server must use forward slashes. Not tested on Windows.
- Calls still do not ring a frozen or killed app.

Update with `arcflare update`, or look first with `arcflare update --check`.
